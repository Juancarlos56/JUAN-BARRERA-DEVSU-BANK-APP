# Frontend — Banco Productos Financieros

Aplicación Angular 21 de la prueba técnica. La documentación completa (ejecución, pruebas,
arquitectura y decisiones técnicas) está en el [README principal](../README.md).

## Comandos rápidos

```bash
npm install
npm start               # http://localhost:4200 (requiere el backend en el puerto 3002)
npm test                # pruebas unitarias con Jest
npm run test:coverage   # pruebas + reporte en coverage/index.html
npm run lint
npm run build
```
